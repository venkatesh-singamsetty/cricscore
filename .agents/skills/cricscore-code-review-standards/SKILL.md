# CricScore Code Review Standards

1. **Review Expectations**: Verify that pull requests strictly address their core objective without introducing feature creep.
2. **Quality Checks**: Ensure appropriate unit tests exist and linters run without errors.
3. **Readability**: Variable names and functions should clearly state their intent without the need for extensive comments.
